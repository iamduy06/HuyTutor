# Huy Tutor Flashcard App

Monorepo chứa toàn bộ mã nguồn hệ thống Flashcard học từ vựng tiếng Anh Huy Tutor:
- `/api`: Backend Express.js + TypeScript (Deploy lên Render)
- `/web`: Frontend Next.js 14 App Router + Tailwind CSS (Deploy lên Vercel)

Chi tiết cấu hình và hướng dẫn deploy xem tại [DEPLOYMENT.md](./DEPLOYMENT.md).
